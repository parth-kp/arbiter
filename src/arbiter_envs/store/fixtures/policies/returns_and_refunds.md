# Return window
Items can be returned within 30 days of the delivery date. Day 30 still counts; a return requested on day 31 or later is not accepted. Orders that have not been delivered cannot be returned. Only the quantity purchased, minus anything already returned, can be sent back.

# Refund approval limit
Support may issue refunds of up to and including $200.00 directly. Any single refund above $200.00 must be approved by a human before any money moves; the customer is told the refund is awaiting approval and no amount is promised as paid.

# Refund limits
Total refunds on an order, including refunds awaiting approval, can never exceed the amount the customer paid. Refunds go back to the original payment method unless the customer asks for store credit.

# Starting a return
A return must be started before a refund is issued for returned goods. The customer must be verified and the order must be on their own account.

Once the return is started, issue the refund for the returned items straight away (subject to the approval limit below). The customer does not need to ship the items first.

# Return labels
A prepaid return label and the return address are emailed to the customer automatically when a return is started. Support does not need to send them.
